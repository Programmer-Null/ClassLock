# ClassLock - 教室电脑锁屏助手

一款专为学校电教委员/机房管理员打造的硬核 WinForms 锁屏软件。旨在防止学生在下课或放学期间乱动班级电脑，同时完美适配希沃白板等触摸大屏设备。

## 核心特性

- 多屏完美适配：自动遍历所有显示器并全屏覆盖。仅在主屏显示操作界面，副屏纯黑防逃逸。
- 触摸屏专属大键盘：内置超大尺寸的自绘触摸数字键盘，完美解决希沃白板等设备系统键盘弹不出的痛点。
- 局域网 UDP 警报系统：当有人在锁屏界面多次输错密码时，程序会向局域网（8888端口）发送 UDP 广播。配合 MonitorCenter 接收端，电教委员可在后台实时抓取“内鬼”IP和机器名。
- 下课摸鱼监控：内置课表时间判断，在下课/休息时间，若检测到有人偷偷打开 Microsoft Edge 浏览器，会立即发送警报并记录。
- 断网物理防御：实时监控网络状态，若检测到网线被拔或网络断开，锁屏界面会立刻亮起红色警告。
- 密码安全存储：采用 SHA256 哈希存储解锁密码，不保存明文，默认初始密码为 123456。
- 防逃逸机制：全局低级键盘钩子（KeyboardHook），强力屏蔽 Win 键、Alt+Tab、Alt+F4、Ctrl+Esc 等系统快捷键。
- 隐藏调试后门：若程序同级目录下存在 Process Monitor，主界面右上角会生成一个隐蔽的小虫子按钮，方便管理员排查异常。

## 技术栈

- 开发语言：C# (.NET Framework 4.8)
- UI 框架：Windows Forms (WinForms) + GDI+ 自绘
- 通信协议：UDP 广播
- 开发环境：兼容 Visual Studio 2013 及以上版本

## 快速开始

1. 编译与运行：使用 Visual Studio 打开项目，切换为 Release 模式生成，运行 Main.exe。
2. 密码说明：默认解锁密码为 123456。密码文件保存在 AppData 目录下，忘记密码直接删除 pwd.dat 即可恢复默认。
3. 壁纸设置：点击主界面的「打开壁纸文件夹」，放入图片即可随机抽取背景。
4. 监控端使用：编译并运行 MonitorCenter 项目，确保在同一局域网下即可接收警报。

## 防翻车指南

- 请勿在学生上课时锁屏，以免影响老师使用 PPT 教学。
- Ctrl + Alt + Delete 是系统底层安全按键，若遇到程序卡死，请使用该快捷键调出任务管理器结束进程。
- 本软件使用了较多 GDI+ 绘制，请勿在老旧核显机器上频繁修改定时器间隔，以免触发驱动崩溃。
